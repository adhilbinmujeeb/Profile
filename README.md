# Adhil — Minimal Portfolio

A responsive, single-page portfolio in a clean monochrome style. Built with plain HTML, CSS and JavaScript. No build tools or paid services required.

## Preview locally
Open `index.html` in a browser. Google Fonts requires an internet connection; local system fallbacks are provided.

## Publish to Vercel (free Hobby tier for personal projects)
1. Extract this ZIP file.
2. Sign in at https://vercel.com/new.
3. Import the folder through a GitHub repository (recommended), or use Vercel CLI (`npx vercel`) in this directory.
4. Framework preset: **Other**. Build command: leave blank. Output directory: `.`.
5. Deploy and Vercel will issue a `*.vercel.app` address.

You can also deploy as a static site to Netlify or GitHub Pages.

## Customize
- All content lives in `index.html`.
- Colors and layouts live in `styles.css`.
- Portrait: `assets/adhil-photo.jpg` (supplied by the portfolio owner).
- Add an email address and an uploaded resume link when you are ready to publish them.
- Academic cybersecurity projects do not have linked public repositories; no links are fabricated.
